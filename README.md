# Demon Slayer: Kimetsu no Yaiba – Fan Page

A responsive one-page website about the anime and manga *Demon Slayer: Kimetsu no Yaiba*, built with plain HTML and CSS as my **1st Practical Project** at Ventspils University of Applied Sciences.

## Features

- **Gradient header** and a navigation bar of useful links, separated by ⚔ icons
- **Story article** with a cover image and an overlaid caption
- **Character ages table** with striped rows and a hover highlight
- **Character cards** laid out with CSS Grid
- **Responsive layout**: columns stack into a single column on screens narrower than 768px
- **Theming** with CSS custom properties and the *Orbitron* font from Google Fonts for headings

## Project structure

```
demon-slayer/
├── index.html      # Page content and structure
├── css/
│   └── style.css   # Layout, colours and responsive rules
└── README.md
```

## Getting started

No build tools are needed.

```bash
git clone https://github.com/KelvinGjohn/demon-slayer.git
cd demon-slayer
```

Then open `index.html` in any web browser.

## Built with

- HTML5 (semantic elements: `header`, `nav`, `main`, `article`, `aside`, `section`, `figure`, `footer`)
- CSS3 (Flexbox, Grid, custom properties, pseudo-elements, media queries)
- [Google Fonts – Orbitron](https://fonts.google.com/specimen/Orbitron)
